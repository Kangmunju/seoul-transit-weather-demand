# 서울 지하철 수요 × 날씨 예측

### 🚇 Streamlit 대시보드
👉 [대시보드 바로가기](https://seoul-transit-weather-demand.streamlit.app/)

서울 지하철 이용량과 날씨 데이터를 결합하여  
날씨가 지하철 수요에 미치는 영향을 분석하고,  
시간순 검증을 통해 수요 예측 모델을 평가한 프로젝트입니다.
단순히 모델의 예측 성능만 확인하지 않고  
강우 효과의 교란 요인, 시계열 데이터 누수,  
팬데믹에 따른 구조 변화까지 함께 분석했습니다.


## 프로젝트 핵심 질문

- 비가 오면 지하철 이용량은 실제로 달라지는가?
- 요일과 계절을 통제해도 비의 효과가 남는가?
- 과거 수요와 날씨로 미래 수요를 예측할 수 있는가?
- 무작위 데이터 분할은 시계열 모델의 성능을
  과대평가할 수 있는가?
- 팬데믹 같은 구조 변화는
  수요 예측에 어떤 영향을 주는가?


## 데이터

분석 기간은 2019년부터 2024년까지입니다.

지하철 이용량과 서울의 일별 날씨 데이터를 수집한 뒤  
SQLite에 적재하고 전처리하여 분석에 사용했습니다.

주요 데이터는 다음과 같습니다.

- 지하철 일별 승하차 이용량
- 평균·최고·최저 기온
- 총강수량
- 강우량
- 적설량
- 최대 풍속
- 습도
- 요일·주말·공휴일 정보
- 팬데믹 국면 정보

현재 지하철 데이터에는 27개 노선이 포함되어 있으며,  
수도권 전철의 모든 노선을 포함하지는 않습니다.


## 데이터 처리 흐름

```text
원본 데이터 수집
      ↓
SQLite 적재
      ↓
지하철·날씨 데이터 정제
      ↓
일 단위 집계
      ↓
지하철 + 날씨 병합
      ↓
달력·팬데믹 특징 생성
      ↓
lag / rolling 특징 생성
      ↓
시간순 모델 학습 및 평가
      ↓
추가 분석
```


## 주요 전처리

### 역명 표준화

역명 뒤에 붙은 괄호 형태의 부기명을 제거하여  
동일 역이 서로 다른 역처럼 집계되는 문제를 방지했습니다.


### 비정상 이용량 처리

`total <= 0`인 값을 발견했을 때  
행 전체를 삭제하지 않고 해당 값만 결측 처리했습니다.

같은 날짜와 역에 존재하는  
다른 정상 승하차 정보를 보존하기 위한 처리입니다.


### 강우와 총강수 구분

총강수량에는 눈이 포함될 수 있기 때문에  
비 효과 분석에는 `precip_mm`이 아니라  
실제 강우량인 `rain_mm`을 사용했습니다.


## 모델링

수요 예측에는 `RandomForestRegressor`를 사용했습니다.

모델에는 날씨와 달력 정보뿐 아니라  
과거 수요를 나타내는 lag 및 rolling 특징을 사용했습니다.

시계열 데이터에서는 미래 정보가  
학습 과정에 들어가지 않도록 하는 것이 중요하기 때문에  
시간 순서를 유지하여 학습과 테스트 데이터를 분리했습니다.


## 시계열 검증

무작위 분할만으로 모델을 평가하면  
미래와 가까운 데이터가 학습 데이터에 포함되어  
실제보다 좋은 성능이 나타날 수 있습니다.

이를 확인하기 위해 다음 평가 방식을 비교했습니다.

- 무작위 분할
- 시간순 분할
- walk-forward 검증

walk-forward 검증에서는  
과거 데이터로 학습한 뒤 그다음 시기를 예측하도록 하여  
실제 운영 환경에 가까운 방식으로 성능을 확인했습니다.


## 팬데믹 구조 변화

시간순 검증에서 2019년으로 학습하고  
2020년을 예측하는 구간의 성능이 크게 저하되었습니다.

추가 분석 결과, 2020년에는  
지하철 이용량 자체가 급격하게 감소했습니다.

이 문제는 단순한 모델 성능 저하가 아니라  
팬데믹으로 인해 기존 수요 패턴이 달라진  
구조 변화와 연결하여 해석할 필요가 있었습니다.

따라서 팬데믹 이전, 급성기, 회복기,  
엔데믹 이후의 수요 변화를 추가로 분석하고  
팬데믹 국면 정보를 모델 특징에도 반영했습니다.


## 분석 구성

```text
analysis/
├── a1_eda.py
│   └── 지하철 수요의 기본 구조와 패턴 분석
│
├── a2_rain_effect.py
│   └── 교란 요인을 고려한 강우 효과 분석
│
├── a3_leakage.py
│   └── 시계열 데이터 누수와 walk-forward 검증
│
├── a4_preprocess.py
│   └── 실제 원본 데이터에서 전처리 문제 검증
│
└── a5_pandemic.py
    └── 팬데믹 전후 수요 구조 변화 분석
```


## 프로젝트 구조

```text
seoul-transit-weather-demand/
├── README.md
├── analysis/
├── data/
├── db/
├── models/
├── outputs/
├── reports/
│   └── analysis_report.md
├── src/
└── .gitignore
```

`src/`에는 데이터 수집, DB 적재, 전처리,  
특징 생성 및 모델 학습 코드가 있습니다.

`analysis/`에는 모델 결과를 해석하고  
데이터의 문제와 구조 변화를 검증하는  
분석 스크립트가 있습니다.

상세 분석 내용은  
`reports/analysis_report.md`에서 확인할 수 있습니다.


## 주요 분석 결과

팬데믹 이전과 이후의 수요 수준에는  
뚜렷한 구조 변화가 존재했습니다.

2020년 지하철 일평균 이용량은  
2019년 대비 약 27.7% 감소했습니다.

이후 이용량은 점차 회복했지만  
2024년에도 2019년보다 약 7.2% 낮았습니다.

또한 팬데믹 급성기에는  
주말 수요가 평일보다 상대적으로 더 크게 감소했습니다.

이 결과는 장기간의 시계열을 예측할 때  
과거 수요 패턴만으로는 설명하기 어려운  
외부 구조 변화가 존재할 수 있음을 보여줍니다.


## 이 프로젝트에서 중점적으로 다룬 문제

이 프로젝트에서는 모델의 점수만 높이는 것보다  
다음 문제를 직접 확인하는 데 중점을 두었습니다.

- 원본 데이터의 품질 문제를 실제 값으로 검증
- 눈과 비를 구분하여 강우 변수 정의
- 시계열 데이터의 미래 정보 누수 방지
- 무작위 분할과 시간순 평가의 차이 확인
- walk-forward를 이용한 시점별 성능 검증
- 팬데믹과 같은 구조 변화의 영향 분석
- 특정 구간의 성능 저하 원인을 데이터에서 추적


## 한계

현재 데이터는 서울·수도권의 여러 철도 노선을 포함하지만  
수도권 전철 전체를 완전히 포함하지는 않습니다.

또한 팬데믹, 대규모 행사, 교통 정책 변화,  
운행 장애처럼 갑작스럽게 발생하는 외부 요인은  
과거 수요와 날씨만으로 완전히 예측하기 어렵습니다.

향후 이러한 외부 데이터를 추가하면  
수요 변화의 원인을 더 정교하게 설명하고  
예측 모델을 개선할 수 있습니다.
